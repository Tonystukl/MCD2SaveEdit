# Changelog

## 0.3.1

- Regular release with updated Windows EXE and complete source.
- Renamed navigation to Quests / Map and rendered literal label text.
- Increased spacing for currency, section headings, gear names, branding and the item-count footer.
- Removed unsupported decorative symbols and set an explicit menu font.
- Experimental quest completion and local fog limitations are unchanged.


## 0.3.0 preview

- Add illustrated Overworld and Sift maps, quest markers, zoom, pan and search.
- Add 42 named quest definitions, objectives and published rewards.
- Complete initialized active/available quest records and grant rewards as one undoable draft change.
- Apply quest XP to level progression and award fixed/weighted gear pools using native item/effect templates.
- Reject duplicate reward claims, unavailable quests, missing native task records, inventory overflow and invalid currency values.
- Restore region fog revealing and add an explicitly experimental local fog preview/reveal.
- Refine typography, dark/light theme and selected-tab styling.
- Package a standalone Windows x64 EXE with its .NET runtime.

Quest script triggers, story gates, exact fog alignment and live reward acceptance remain unverified. This is a preview release.

## 0.2.4

- Cap inventory/equipment card sizes and prevent overlapping gear fields.
- Add the application icon, Sharpness bonus and Protection strength editing.
- Track active Xbox save revisions and verify full-account backups.
- Add named gear/enchantment catalogues and preserve four armor slots, artifacts, talismans and currencies.
